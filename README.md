## Using matrix_invert.py
File takes in a matrix of any size (>2) and prints the inverse matrix and creates a csv file of the inverse. The first argument corresponds to the input csv and the second augment to the output csv. 

#### Example
	python matrix_invert.py .\input_matrix.csv .\output_matrix.csv

## Using apply_matrix.py
File takes in a matrix and vector of any size (>2) and prints the resultant vector while creating an output vector csv.

> **NOTE:** This code assumes that the size of the matrix will match the size of the vector.

### Example
	python apply_matrix.py .\output_matrix.csv .\input_vector.csv .\output_vector.csv
